Computer Vision 2024

Real-Time Object Detection

YOLOv8-powered detection system for real-time video stream analysis achieving 92% mAP at 45 FPS on edge hardware. Deployed for industrial quality control.

↗ View on GitHub ← All Projects
The Problem

Detecting defects faster than the human eye

A manufacturing client needed to automate quality control inspection on a conveyor belt running at 2m/s. Human inspectors were catching only ~70% of defects and fatiguing within hours. The challenge: build a vision system that runs in real-time on NVIDIA Jetson hardware without internet connectivity.

The system needed to detect 12 defect classes simultaneously across varying lighting conditions, with less than 50ms latency per frame to not block the production line.

Approach

Engineering pipeline

01 / Data Acquisition

15K Annotated Frames

Captured 15,000 frames from production line cameras. Used Roboflow for bounding box annotation across 12 defect classes.

02 / Augmentation

Synthetic Data Pipeline

Applied mosaic augmentation, random brightness, and perspective transforms to simulate real factory lighting variations.

03 / Training

YOLOv8-m Fine-tuning

Fine-tuned YOLOv8-medium on custom dataset. Used cosine annealing LR schedule with early stopping on validation mAP.

04 / Optimization

TensorRT Export

Exported model to TensorRT FP16 for 3× speedup on Jetson Orin. Achieved 45 FPS real-time inference on edge device.
