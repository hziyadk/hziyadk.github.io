Sentiment Analysis Engine

Multi-class sentiment classification using transformer-based models on Indonesian social media text. Built to handle code-mixing (Bahasa + English) with 89% F1-score.

↗ View on GitHub ← All Projects
The Problem

Why does sentiment matter in Indonesian social media?

Indonesian social media generates millions of posts daily, mixing Bahasa Indonesia, regional dialects, and English slang. Standard sentiment tools trained on English data fail completely — misclassifying sarcasm, slang, and informal abbreviations that are common in Indonesian online communication.

The goal was to build a production-ready classifier that handles this linguistic diversity and correctly predicts Positive, Negative, and Neutral sentiment across 5+ social media platforms.

Approach

How it was built

01 / Data Collection

120K Labeled Tweets

Scraped and manually labeled 120,000 Indonesian tweets across 5 categories using Twitter API and semi-supervised labeling.

02 / Preprocessing

Normalization Pipeline

Custom tokenizer for Bahasa slang, emoji handling, and code-mixing detection. Built with HuggingFace Tokenizers.

03 / Modelling

Fine-tuned IndoBERT

Fine-tuned IndoBERT-base on labeled dataset with layer-wise learning rate decay and mixed precision training.

04 / Deployment

FastAPI + Docker

Wrapped model as REST API with FastAPI. Containerized with Docker, deployed on GCP Cloud Run for scalability.
