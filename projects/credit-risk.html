Credit Risk Prediction Model

An ensemble machine learning approach to predict loan default probability, helping financial institutions minimize risk and approve loans faster.

↗ View on GitHub ← All Projects
The Problem

Mitigating risk in lending

Assessing the creditworthiness of loan applicants manually is slow and prone to human bias, leading to either high default rates or rejection of good candidates.

The objective was to build a robust predictive model that accurately assesses the probability of default based on applicant history and demographic data, ensuring fair and data-driven lending decisions.

Approach

Data-driven modeling

01 / Data Cleaning

Handling Imbalance

Addressed class imbalance in historical loan data using SMOTE techniques to ensure the model learns to identify minority default cases effectively.

02 / Feature Engineering

Creating Variables

Engineered features capturing debt-to-income ratios, payment history trends, and credit utilization rates to improve model discriminative power.

03 / Model Selection

Ensemble Learning

Trained and tuned multiple models including XGBoost, LightGBM, and Random Forest, combining them into a powerful ensemble.

04 / Explainability

SHAP Values

Implemented SHAP (SHapley Additive exPlanations) to interpret model predictions, providing transparency for regulatory compliance and business users.
