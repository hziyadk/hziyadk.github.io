Sales Intelligence Dashboard

Interactive analytics on 3M+ transactions with drill-down capabilities and predictive insights to drive business strategy.

↗ View on GitHub ← All Projects
The Problem

Unlocking insights from massive data

The company was struggling to make sense of over 3 million transaction records scattered across different regional databases. Generating a simple monthly sales report took days of manual Excel work, leading to delayed decision-making.

They needed a unified, real-time dashboard that not only visualized historical data but also provided predictive insights into future sales trends and customer churn probability.

Approach

Data Pipeline & Visualization

01 / ETL Pipeline

Data Integration

Built automated ETL pipelines using Python and Airflow to consolidate data from 5 regional PostgreSQL databases into a central data warehouse.

02 / Data Modeling

Star Schema

Designed a star schema data model optimized for fast analytical queries and aggregations across millions of rows.

03 / Predictive Analytics

Trend Forecasting

Integrated a predictive model to forecast next month's sales based on historical seasonality and recent trends.

04 / Dashboard UI

Plotly Dash

Developed an interactive, responsive dashboard using Plotly Dash with drill-down filters for region, product, and time period.
