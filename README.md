# Hauzan Ziyadatul Khoir — Portfolio

> Data Scientist & AI Engineer Portfolio Website

A modern, dark-themed portfolio website built with pure HTML, CSS, and JavaScript. Inspired by [bazil.fr](https://en.bazil.fr/), adapted for a Data Science & AI Engineer profile.

## 🌐 Live Demo
[View Portfolio](https://YOUR_USERNAME.github.io/Portofolio/)

## 📁 Structure
```
Portofolio/
├── index.html          # Home page
├── projects.html       # Projects gallery with filter
├── about.html          # About me page
├── style.css           # Global design system
├── script.js           # Animations & interactions
└── assets/
    └── images/         # Project thumbnails & profile photo
```

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository named `Portofolio` (or any name)
2. Push all files to the `main` branch
3. Go to **Settings → Pages**
4. Set source to **Deploy from branch → main → / (root)**
5. Your site will be live at `https://YOUR_USERNAME.github.io/Portofolio/`

## ✏️ Customization

- **Profile photo**: Replace `assets/images/profile.png` with your actual photo
- **Projects**: Edit `projects.html` to update project titles, descriptions, and images
- **Bio**: Edit `about.html` to update your bio, experience, and skills
- **Social links**: Update GitHub, LinkedIn, and Kaggle links in `about.html`
- **Colors**: Customize CSS variables in `style.css` under `:root`

## 🛠️ Tech Stack
- HTML5 · CSS3 · Vanilla JavaScript
- Google Fonts (Space Grotesk, Inter, Space Mono)
- No frameworks, no build tools needed
